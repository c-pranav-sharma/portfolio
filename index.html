01

GNSS Observatory

Large-scale geospatial anomaly detection platform

May 2026 — Present

A two-region platform that ingests a full year of aircraft telemetry and surfaces corroborated navigation-integrity anomalies with reproducible evidence bundles. Designed, built, and operated end to end.

  • 692M aircraft position fixes and 173M navigation-integrity samples from 23,600 aircraft, at 98.1% temporal coverage with zero unexplained gaps.
  • Storage and feature layer in TimescaleDB + PostGIS using H3 hexagonal indexing, aggregating raw telemetry into 52.6M cell-windows with rolling 30-day baselines.
  • Three unsupervised detectors and a cross-signal fusion stage surfaced 52 corroborated events, each written to object storage with a SHA-256 evidence bundle.
  • 70% detection sensitivity at a 1.5% false-positive rate against held-out control airspace; a corroboration rule cut false positives from 14.7% to 0.07% where threshold tuning alone had plateaued at 4.8%.
  • Dockerized pipeline on AWS EC2 with versioned SQL migrations; identified 13 silent data-scoping defects and added SQL-inspecting regression tests that assert query correctness rather than output values.

AegisBERT

Zero-day threat intelligence engine

April 2026

A transformer service that reads unstructured security advisories and classifies them into threat categories fast enough to sit inside a live triage loop.

  • Fine-tuned ModernBERT on 150,000+ custom-mined CVEs across 13 threat categories, automating vulnerability classification over unstructured advisories.
  • Automated NVD ingestion with hybrid weak labeling (CWE taxonomy mapping plus regex heuristics), eliminating manual annotation across the entire training corpus.
  • Flash Attention and mean pooling drove inference under 200 ms at an 8192-token context window.
  • Dockerized microservice architecture: an async FastAPI inference API paired with a Streamlit analytics dashboard for real-time triage.
